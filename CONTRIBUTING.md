# Contributing Guidelines

Thank you for your interest in contributing to the Simple Interest Calculator project!

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork this repository.
2. Clone your forked repository to your local machine.
3. Create a new branch for your changes.
4. Make the necessary changes.
5. Test your changes to ensure everything works correctly.
6. Commit your changes with a clear and descriptive commit message.
7. Push your changes to your forked repository.
8. Submit a Pull Request describing your changes.

## Reporting Bugs

If you find a bug, please open an issue and provide:
- A clear description of the problem.
- Steps to reproduce the issue.
- Expected and actual results.
- Screenshots, if applicable.

## Suggesting Enhancements

Suggestions for new features and improvements are welcome. Please open an issue explaining your idea and how it could improve the project.

## Documentation Improvements

Contributions to improve the README file, instructions, and other project documentation are encouraged.

## Code of Conduct

All contributors are expected to follow the project's Code of Conduct and maintain a respectful and welcoming environment.

## Thank You

Thank you for helping improve this project. Every contribution is appreciated!
